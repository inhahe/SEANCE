Script Console

The Script Console (Tools → Script Console) is a Python prompt that edits your project: it can add nodes, wire them together, place notes, move markers, write automation — and, when you're done, bounce the whole thing to a WAV file without you touching the transport. Think of it as a macro recorder you type into rather than a live instrument.

This is not the same thing as the Script node. The Script node runs inside the audio graph, once per sample or per block, making sound in real time. The Script Console runs once, on your project file, like a batch edit. Different job, different language, different page.

Everything lives in one module:

import soundshop as ss

Your first script

Open Tools → Script Console, paste this, and press Run:

import soundshop as ss

track = ss.add_midi_track("Melody")
clip  = ss.add_clip(track, 0, 4)

beat = 0
for pitch in ss.scale_pitches("C", "Major", 4):
    ss.add_note(track, clip, pitch, beat, 0.5)
    beat += 0.5

A new MIDI track appears with a C major scale written into it. Two things to notice:

  • scale_pitches("C", "Major", 4) gave you [60, 62, 64, 65, 67, 69, 71] — the same seven notes the piano roll would highlight if you picked C / Major in its Key and Scale menus. It's literally the same table, so the script and the editor can't disagree.
  • Positions are in beats, not seconds or samples. 0.5 is an eighth note. Change the tempo afterwards and everything still lines up.

Wire the track to a synth by hand, or from the script: ss.add_link(track, ss.find_node("Output")).

Letting SEANCE do the music theory

You don't have to know what a Dorian mode is to use one. Ask:

ss.scale_names()          # every scale SEANCE knows
ss.scale_names("mode")    # just the seven modes
ss.scale_intervals("Dorian")   # [0, 2, 3, 5, 7, 9, 10]

Names are forgiving — "natural minor", "Natural Minor" and "naturalminor" all work. So do note names anywhere a pitch is expected: ss.add_note(track, clip, "C4", 0, 1) is the same as writing 60.

A few things worth knowing about:

  • Snap something into a scale. ss.snap_to_scale([61, 66, 70], "C", "Major") nudges each note to the nearest one that belongs. Handy after a random-note generator.
  • Change key without wrecking the melody. ss.change_key(pitches, "C", "Major", "D", "Natural Minor") works out what role each note played (first note of the scale, third, fifth…) and finds the note playing the same role in the new key. That's different from just shifting everything up two semitones — it's what the piano roll's Change Key button does.
  • Ask what key something is in. ss.detect_key([60, 62, 64, 67, 69]) returns candidates best-fit-first; the top one here is C Major Pentatonic with coverage 1.0 (every note fits).
  • Analyse one note. ss.note_degree(64, "C", "Major") tells you it's the 3rd, in octave 4, and in the scale.

Octave numbers are the ordinary ones: middle C is C4 = 60, the same as the labels down the side of the piano roll.

Bouncing to a file

When the project sounds right, render it:

ss.render("D:/music/take1.wav")

That's the same renderer as File → Export Audio — same result, same default span (everything with content, plus four beats of tail so reverbs finish). Pass end_beat=32 to bounce a specific length, or sample_rate= / channels= / bits= to change the format. The file extension picks the encoder, so .flac works too.

Paths must be absolute. "take1.wav" would land in whatever folder SEANCE happens to think it's running from, which is never where you're looking. Write the whole path.

You get back a small summary you can print or check:

info = ss.render("D:/music/take1.wav")
print(info["seconds"], "seconds,", info["frames"], "frames")

If you want the audio as numbers rather than a file — to check the peak level, compare two takes, or feed it somewhere else — use render_samples():

r = ss.render_samples(end_beat=8)
peak = max(abs(v) for v in r["data"][0])
print("left channel peak:", peak)

Making a sound from scratch

The last piece: you can compute a waveform in Python and put it into the project. write_wav takes plain numbers in the usual −1…+1 range and writes an audio file; set_audio_file drops that file onto a clip.

import soundshop as ss, math, array

sr = 48000
tone = array.array('f', (0.5 * math.sin(2*math.pi*440*i/sr) for i in range(sr)))
ss.write_wav("D:/music/tone.wav", tone, sample_rate=sr)

t = ss.add_audio_track("Tone")
c = ss.add_clip(t, 0, 4)
ss.set_audio_file(t, c, "D:/music/tone.wav")
ss.add_link(t, ss.find_node("Output"))

Press play and you'll hear a one-second 440 Hz tone. Anything you can compute — a chirp, shaped noise, a resynthesis, an impulse response for the Convolution Filter — can get into a project this way. read_wav("…") goes the other direction, handing you an existing file's samples to analyse or mangle.

For a stereo file, pass a list of channels instead of one: ss.write_wav(path, [left, right]). If one channel is shorter than the other it's padded with silence rather than rejected.

Why array('f') and not a plain list? You can pass a list — it works fine for short things. But a three-minute stereo render is about seventeen million numbers, and Python lists of that size cost hundreds of megabytes. array('f') (and NumPy arrays, if you have NumPy) are single blocks of memory, so SEANCE hands renders back in that form and takes them back the same way.

Shortcuts for common jobs

Two helper modules ship with SEANCE and are importable straight away:

import soundshop_tools as tools

tools.add_scale(track, clip, "D", "Dorian", octave=4, ascending=True, descending=True)
tools.add_chord_progression(track, clip, "C", [("I", 4), ("V", 4), ("vi", 4), ("IV", 4)])
tools.add_arpeggio(track, clip, "C4 E4 G4", pattern="updown", repeats=4)
tools.add_rhythm(track, clip, 36, "x..x..x.")   # kick pattern
tools.print_project()                            # what's in this project?

soundshop_music is the other one — it's about writing notes down: Note and Notes objects that carry a spelling ("Bb3", "F#4"), a velocity, a length in beats. tools.notes_to_timeline("Melody", "C4 E4 G4 C5") parses a note string and drops it on a track by name.

Things to watch out for

  • Ctrl+Z does not undo a script. Script Console edits go straight into the project without creating an undo step. Save before you run something that restructures things.
  • The console is optional. SEANCE can be built without Python; if yours was, Tools → Script Console tells you so rather than pretending.
  • Your own modules work. Drop a .py file next to the bundled ones in SEANCE's scripts/ folder and import it like any other.

The complete list of functions, with exact arguments, return values and edge cases, is in the Script Console section of REFERENCE.md in the SEANCE project folder.

Layers & Effect Groups

Home Graph Basics

Most DAWs treat "which effects are active" as a fixed property of a track. In SEANCE you can make that time-varying — a given effect wire can be on only during certain beat ranges, and off otherwise. This section is about how that works.

The problem

Suppose you have a synth track feeding into a reverb, and you want the reverb active only during the chorus. In a traditional DAW you'd automate a dry/wet knob. In SEANCE you can instead mark the wire between the synth and the reverb as time-gated, with bright-colored regions showing where the gate is open.

Layers (effect regions)

A layer is a time range during which a specific cable is active. Outside that range the wire is muted, with a short crossfade at the edges so you don't hear a click (see Options → Crossfade Duration).

Where layers live: the Effects lane

Open a track's piano roll and look just above the note grid. Above the Start strip there's a thin band labelled ▸ Effects on the left. That's the Effects lane, and it's where all of this happens. It's always there — if the track has no layers yet it just says "no effect layers — click to add one".

Layers show up in the lane as coloured tubes, one row per wire or group, each tube spanning the beats where that routing is switched on.

Making your first layer

  1. Click the Effects lane. It expands, giving you room to work. (You can also right-click it directly.)
  2. Right-click at the beat where you want the effect to come in, and choose Add layer at beat N…
  3. Pick what to gate — either an effect group, or a single wire listed as Source → Destination. For the reverb example above you'd pick Synth → Reverb. The little coloured square next to each entry is the colour the tube will be, so you can pick by colour once you know your project. If two wires run between the same pair of nodes, they're spelled out with the plugs they use, like Voice In 2 → Signal Osc  (Gate → Gate).

You get a 4-beat tube in the wire's colour. Now shape it:

  • Drag its middle to slide it earlier or later.
  • Drag either end to make it longer or shorter — the cursor turns into a ↔ arrow when you're on an end.
  • Drags snap to the piano roll's grid. Hold Alt to position freely.
  • Right-click a tube to delete it.

When you're finished, collapse the lane back to its thin ribbon: press Escape, click the ▾ Effects caption on the left, or right-click → Done editing.

Each layer is coloured to match the wire (or group) it gates, so you can tell at a glance which routing is being switched on and off.

Layers belong to the track, not the timeline. If you slide a track's start position left or right in the Start strip, its layers slide with it and keep gating the same music. The same is true when you insert or delete time.

Effect groups

Sometimes you want to activate multiple wires at once — e.g., a reverb send AND a delay send AND a filter mod, all gated as one "chorus effects on" layer. That's what an Effect Group is: a named bag of wires that can be activated together.

To create an effect group:

  1. Right-click a wire → Effect Group → New Group…
  2. Give it a name
  3. Right-click other wires → Effect Group → Add to [group name]

Then go to the Effects lane of the track you want to control it from, right-click → Add layer…, and pick the group instead of a single wire. All wires in the group now activate and deactivate together. Each group gets its own color drawn on member wires (circles for wire identity, diamonds for group membership).

The routing strip

Above the piano roll, a narrow routing strip appears when any layers exist. It shows each gated wire as a horizontal "wire" bar with 3D shading, colored to match its wire/group. The horizontal axis matches the piano roll below, so you can see at a glance which wires are active at which beats across the whole project.

Crossfade edges

When a layer turns on or off, the wire crossfades over a short time so you don't hear a click. The default is 50 ms, set globally via Options → Crossfade Duration. An effect group can override the global duration if it has a non-zero crossfadeSec value, otherwise it inherits.

Tip: layers are a good way to think about arrangement differently than "track A is always there, track B comes in later." Instead of duplicating tracks, route everything through one track and use layers to gate routing on and off over time.

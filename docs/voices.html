Voices (Polyphony)

Home Graph Basics Terrain Synth

Every built-in synth in SEANCE is already polyphonic on its own — play a chord into a Wavetable or FM synth and it sounds all the notes. But the recipe for each note (the oscillators, filters, and envelopes) is sealed inside that instrument. What you couldn't do until now was take a few separate graph nodes — say an oscillator, a filter, and an envelope — and have that little patch played once per note you press, with all the copies summed together. The Voice container adds exactly that. It's how you build your own polyphonic instrument out of ordinary nodes.

The one-sentence version: a Voice container is a node that holds a small patch (a "voice") and runs one independent copy of it per note you play, mixing them all to a single audio output.

Add one and hear it

Right-click an empty spot on the graph and choose Add Node → Instruments → Voice (polyphonic)…. You get a single node on the canvas with a MIDI input on the left and a stereo audio output on the right — it looks and wires up like any other instrument. Wire a note source into its MIDI input (a Computer Keyboard node, a Timeline, or a hardware MIDI input) and wire its audio output to your Mixer or the Output node.

It comes pre-loaded with a working patch — a small FM synth inside — and 8 voices, so it makes sound the moment you wire it up. Play a chord: each note spins up its own copy of the inner patch, and you hear them stack. That's polyphony built from a container instead of baked into a fixed instrument.

Why "8 voices"? That's how many notes can sound at once. The container builds 8 independent copies of the inner patch up front and hands a free one to each note you play. If you play a 9th note while 8 are still ringing, the oldest one is cut short to make room (this is called "voice stealing"). Idle copies cost almost nothing, so a high voice count is cheap until you actually play that many notes.

Going inside — drill in

Double-click the Voice node to go inside it. The graph editor switches to a scoped view: it now shows only the nodes that live inside this container, and hides everything at the top level. A small breadcrumb chip appears in the top-left corner ("← Root / Voice") to remind you where you are.

To come back out, either click the breadcrumb chip or press Esc. Anything you do inside — adding nodes, wiring cables, editing parameters — affects only this voice's patch.

Nodes you add while inside join the voice automatically. Right-click → Add Node while you're scoped into a container and the new node is created inside that container, not at the top level. So drilling in is also how you build the patch.

The two boundary pucks: VoiceIn and VoiceOut

Inside the container you'll find two special little nodes that mark the edges of the patch:

  • VoiceIn (left) — the source of everything about the note being played. It hands the note to your patch in two different forms at once (see below), so you can build the voice whichever way suits you.
  • VoiceOut (right) — the audio sink. Whatever you wire into VoiceOut is this voice's sound; the container sums VoiceOut across all the sounding voices into its single output. Every patch must end at VoiceOut to be heard.

VoiceIn offers the note in two forms:

  1. MIDI — the note as an ordinary MIDI stream. Wire this into any existing MIDI synth (FM, Wavetable, SoundFont, a hosted plugin) and it just works, one instance per voice. This is what the default patch uses, and it's the fastest way to make a container sing.
  2. Pitch / Gate / Velocity — the note broken out as three control signals: Pitch in Hz, a Gate that's 1 while the key is held and 0 after you let go, and Velocity (how hard you struck it). These are for building a voice out of raw signal-driven modules — the modular-synth path.

Build a modular voice with the Signal Oscillator

The Signal Oscillator is the first instrument that reads its note straight from those Pitch/Gate/Velocity signals instead of from MIDI — which is what makes the signal half of VoiceIn useful. Add one from Add Node → Signal Shape → Signal Oscillator (pitch/gate → tone) while you're inside a container.

It has three signal inputs and turns them into a tone:

  • Pitch (Hz) — sets the oscillator's frequency, read every sample, so pitch can glide and bend smoothly.
  • Gate (0/1) — starts the note (and its envelope's attack) the instant it rises above ½, and releases the note when it falls back to 0.
  • Velocity (0..1) — how hard the note was struck; scales the envelope.

It has a Waveform control (sine / saw / square / triangle), a Volume, and the shared AHDSR envelope — right-click it → Envelope (AHDSR)… to shape the attack, decay, sustain, and release just like any other synth.

To wire up a complete modular voice:

  1. Double-click the Voice container to go inside.
  2. Delete the default FM synth (select it, press Delete).
  3. Add a Signal Oscillator.
  4. Wire VoiceIn Pitch → Signal Oscillator Pitch, VoiceIn Gate → Gate, and VoiceIn Velocity → Velocity.
  5. Wire Signal Oscillator audio → VoiceOut.
  6. Press Esc to pop back out, and play.

Now insert a filter, an LFO, a second oscillator — any nodes you like — between the oscillator and VoiceOut, and the whole patch is cloned per note. That's a synth voice you designed, made polyphonic by the container.

The Signal Oscillator is monophonic on purpose. A single Signal Oscillator only plays one note at a time. You don't add polyphony to the oscillator — you let the Voice container provide it by cloning the patch. (Dropped outside a container, the Signal Oscillator still works as a standalone tone you can drive from any signal source — an LFO into its Pitch, say.)

Current limitations

This is the first version of the feature. A few things are intentionally simple for now:

  • The voice count is fixed when you create the container (default 8) — there's no live slider yet.
  • When all voices are busy, the oldest note is always the one stolen.
  • You can't put a Voice container inside another Voice container.
  • Adding a node that opens a file picker (a hosted plugin, a SoundFont, a WASM module) lands it at the top level even if you're scoped inside a container — drag it in afterward, or recreate it inside.

Trigger Node

Home

A Trigger node sits on a MIDI path and fires additional events when notes pass through. For each incoming note-on, a rule list evaluates — matching rules can either generate delayed or offset MIDI notes (chord, octave, flam, arpeggio) or start parametric signal shapes (envelope, step, ramp) on the Signal output. Presets cover the common cases (Octave Double, Chord I-III-V, Flam, Pluck envelope, Velocity follower).

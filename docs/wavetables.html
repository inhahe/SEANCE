Wavetables & Layered Waveforms

Home Graph Basics

The Layered Waveform editor is where you build sounds for the Waveform synth. Instead of picking a single wave shape (sine, saw, square) like a basic oscillator, you stack multiple shapes together as layers, each tuned and balanced however you like, and the editor sums them into a single playable cycle. Stack several of those cycles into a wavetable and you get a sound that morphs as the synth plays.

Open it by double-clicking any Waveform synth node, or by adding a new one (right-click empty graph → Instruments → Waveform).

Layers

A layer is one wave source with three knobs:

  • Wave source — what generates this layer's cycle. Click the layer's wave-source button (it shows the current source's name) to open one menu. The top Custom shapes section is for shapes you make yourself: Draw your own (freehand), Formula (a typed math expression), Use Library… (pull a single cycle from your project's asset library for this one layer), Save to Library… (publish this layer's current cycle to the asset library), and Unlink from Library (break this layer's live link to a saved waveform while keeping its current cycle — greyed out unless the layer is currently linked). The Presets submenu has ready-made starting cycles in two groups: Simple — the param-free basics Sine, Saw, Square, Triangle, Noise (no extra knobs) — and With parameters, the wave-defining generators PWM, Hard Sync, FM, Phase Distortion, where a knob is the wave. A layer has exactly one wave source; picking a new one replaces the old. Choosing a generator reveals its own knob(s) right below (PWM's Duty, FM's Index/Ratio, …), and each of those knobs has its own Pin checkbox so you can modulate it live. Use Library… shows a Sync to library checkbox: leave it on to keep this layer live-linked to the stored waveform (edits to either side flow both ways), or turn it off to drop in a one-time independent copy. (Built-in factory shapes always copy.)
  • Harmonic — what multiple of the root pitch this layer cycles at. 1 means the same as the played note (the fundamental); 2 is one octave up; 3 is one octave + a fifth; higher numbers add brighter overtones. This is how you sculpt timbre — sine layers stacked at integer harmonics give organ-like additive sounds; non-integer harmonics give bell-like inharmonic textures.
  • Phase — where in its cycle the layer starts (0 to 1). Doesn't matter for a single sine but affects how layers add up — two sines at the same pitch but opposite phase cancel completely; phase shifts between layers reshape the combined waveform. Tick the small Mod box next to it to drive the phase live from a cable (LFO, envelope, …).
  • Amplitude — how loud this layer is in the sum (0 to 1). Use to balance layers against each other. Also carries a Mod box so you can drive a layer's level live.

Ticking a Phase or Amplitude Mod box exposes an input pin on the node so a cable can drive that value live. The slider stays editable — dragging it sets the resting value the modulation swings around — and only greys out (signal-locked) if you wire a Set (absolute) cable to the pin, which fully takes over the value; disconnect it or switch the pin to Mod to edit by hand again. This works on single- and multi-frame tables alike — the synth re-bakes just that frame as the modulation moves.

A layer reshapes its own cycle only through its wave source (a Type-1 generator like Pulse / FM / Phase Distortion). To reshape the combined sound of all layers, use the Summation Morph strip below the preview (see Morphing & shape-bending below).

Click + Add Layer to stack more on top. Each new layer defaults to the next harmonic (1, 2, 3, …). Click the X on a layer to remove it. The waveform preview at the top updates live as you tweak.

To actually hear the cycle you're building, press the green Preview button near the bottom of the editor (every frame editor and capture dialog puts a Preview button in the same spot). It sustains a note through the synth's own envelope and volume so you can audition the waveform on its own — even before you've placed it into a wavetable grid. Keep editing while it plays: every change you make is heard live. Click again (it turns red and reads Stop) to release the note.

The Drawn shape

Pick Drawn on a layer to switch its shape from a math curve to a freehand canvas — drag in the layer's preview to draw the shape directly with the mouse. Useful when you want a specific transient or asymmetry that no math primitive gives you.

The Formula shape

Pick Formula to type a math expression instead of picking a fixed wave. The expression is evaluated over one cycle in the variable x, which sweeps from 0 to 2π (one full turn), and the result is clamped to the −1…1 range. So sin(x) is a plain sine, tanh(3*sin(x)) is a softly-overdriven sine, and sin(x) + 0.3*saw(3*x) adds a third-harmonic sawtooth bite. You have the usual math vocabulary available: sin cos tan asin acos sinh cosh atan asinh acosh atanh sqrt inversesqrt abs sign exp exp2 log log2 floor ceil round roundEven trunc fract mod min max pow clamp mix step smoothstep fma saw square triangle noise radians degrees, plus pi and e. (These mirror the GLSL shaping functions — the Built-in language covers the complete scalar set of GLSL's trig/exponential/common builtins — so a shape ports cleanly between the Built-in and GLSL languages.) You can also apply the same shape-bending transfers as the Warp strip below right inside a formula: warpamp(method, value, amount) shapes a sample (clip / fold / saturate / …) and warpphase(method, phase, amount) bends a read position, where method is the warp's name or number, amount is 0…1 (0 does nothing), and the method comes first. So warpamp("soft clip", sin(x), 0.8) overdrives a sine with the exact Soft Clip curve the Warp strip uses.

A formula can also be more than one line: build several waves as named pieces and combine them. Put each statement on its own line (or separate them with ;), assign with =, and the last line is the result. For example:

a = sin(x)
b = 0.5 * sin(3 * x)
a + b

makes two oscillators and adds them together — the same idea as adding harmonics inline, but easier to read when you're stacking several. (Lua, Python and GLSL formulas can do this too, using their own local-variable syntax.)

Next to the expression field is a small language dropdown with four choices:

  • Built-in (default) — SEANCE's own expression language. Fast, always available, and evaluated live.
  • Lua — write the shape as a little Lua program. Handy if you already know Lua or want loops/locals to build up a complex shape. A bare expression like sin(x) works as-is; for a longer program, end it with return <value>.
  • Python — same idea in Python. Generator-style one-liners like sum(0.6**k * sin((k+1)*x) for k in range(6)) are a quick way to stack harmonics.
  • GLSL — write the shape as a GPU compute shader (the body of float shapeValue(float x, float f, int i, int n)). This is the most capable waveshaping option: full GLSL math, the TAU constant, and waveform(id, phase) to sample any of the ~4000 factory waveforms right inside your expression. It runs once on an offscreen GPU context — never while audio plays. Needs a reasonably modern graphics driver (OpenGL 4.3); if yours is too old the option is greyed-out with a tooltip explaining why.

Lua, Python and GLSL shapes are computed once, in the background, the moment you finish typing — they never run while audio is playing, so they can't cause clicks or dropouts no matter how heavy the math is. If your script has a mistake, a red Script error message appears over the layer preview telling you what went wrong, and the layer stays silent until you fix it. A language that isn't available shows up greyed-out with a tooltip explaining why. The built-in language and Lua always work; Python is optional — SEANCE runs fine without it, but the Python option only lights up when a matching Python interpreter is installed (install Python and restart to enable it) — and GLSL needs an OpenGL 4.3-capable graphics driver.

Inharmonic stacks (bells, mallets, metallic tones)

Stacking sine layers at whole-number harmonics (1, 2, 3, …) gives you organ-like and vocal timbres — the overtones line up into a pitched, "musical" tone. But bells, gongs, chimes, marimbas, and most metallic or struck sounds have overtones that don't line up on whole numbers. That clangy, shimmering quality comes from inharmonic partials at ratios like 2.76 or 5.40 times the root.

Press + Waveform and pick Inharmonic stack (additive) to make one. You get a list of partials, each with three controls:

  • Ratio — the partial's pitch as a multiple of the played note. 1 is the note itself; 2 is an octave up; 2.76 is a non-whole-number overtone that makes the tone bell-like. This is the control that makes the sound inharmonic.
  • Amp — how loud that partial is (0 to 1).
  • Phase — where in its cycle the partial starts. Mostly affects the attack character.

Use + Partial to add more (up to 64), the X on a row to remove one, and the Bell button to drop in a ready-made set of classic bell ratios as a starting point — tweak from there. Press Preview to audition it.

Unlike the other waveform kinds, an inharmonic stack isn't a single repeating cycle — the synth plays one sine oscillator per partial, live, each at the note's pitch times its ratio. That's what lets the partials sit at any ratio at all. It plays at the same loudness as the thumbnail shows, blends on the Position axis alongside your other waveforms just like any frame, and never aliases when you play high notes (partials that would go above the audible limit simply drop out).

Factory waveforms (the built-in library)

You don't have to build every waveform from scratch. SEANCE ships with a library of thousands of ready-made single-cycle shapes — clean geometric waves, cycles sampled from real instruments (pianos, organs, guitars, strings, brass, woodwinds, voice), and a big pile of synthetic and character waves (FM, distorted, chiptune, video-game, and more). They come from the public-domain Adventure Kid Waveforms set.

Press + Waveform and pick Factory waveform… to open the browser:

  • Categories run down the left (with an All categories row at the top). Click one to see just its waveforms.
  • Search at the top filters by name or category — type "oboe", "saw", "bell", etc.
  • Curated only is a toggle that narrows the list to a hand-picked "best of" subset. Those waveforms are also marked with a gold ★ and sorted to the top of every category, so even with the toggle off the good ones are easy to find. If thousands of choices feels like too much, flip Curated only on and browse a tight, vetted set instead.
  • Click a waveform to see its shape in the preview at the bottom; double-click (or select it and press Insert) to add it.

The waveform you pick lands in the Library as a normal, fully-editable waveform — it's imported as a hand-drawn (freehand) layer, so you can draw over it, stack more layers on top, bend it with shape-bending (warp), or use it as-is. Like any new library entry it isn't placed in the arrangement yet; drop it into a cell with Assign to selected cell or by dragging its row.

The waveform library

Every waveform you create lives in the Library list on the right side of the wavetable window. The library is just the set of waveforms that exist — placing one into the morphing arrangement (the grid or scatter view) is a separate step, so you can build up a palette of shapes and then decide where each one goes.

  • Click a row to highlight it — that waveform opens in the editor on the left, and any edits you make flow into every cell that references it.
  • + Waveform adds a new waveform to the library. When the list is long enough to scroll, it automatically scrolls down so the new entry is in view.
  • Press Del (or Backspace) while a row is highlighted to delete that waveform. Any cells or dots that referenced it become empty. (The X on the row does the same thing.)
  • Right-click a row for a menu with Add to grid (drop it into the arrangement), Duplicate (make an independent copy in the library), and Delete.
  • Drag a row onto the arrangement view to place that waveform at the cursor (or into a cell in Grid mode).

A newly-created waveform isn't placed in the arrangement yet, so it has no grid position. While it's highlighted but unplaced, the "Selected waveform position" controls are replaced by an Add to grid button — click it to drop the waveform into the arrangement (it fills the first empty cell, growing the grid if it's full), and the position controls reappear so you can move it around.

To replace the highlighted waveform with one from the library, use the Use Library… button on the editor's name/colour row. Because this swaps the whole frame (all its layers), the picker leads with the frames you've saved — pick one to drop it in (tick Sync to library to keep it live-linked, so later edits flow both ways). Below a "Start over with a single cycle" divider you'll also find the full factory single-cycle catalog (the AKWF_* shapes); picking one of those starts the frame fresh as a single layer. (The per-layer Use Library… inside the wave-source menu is the other way around — single cycles first — because there a single cycle is the layer.)

Making one waveform louder or quieter

Here's a gotcha that surprises people: every waveform you build is automatically normalised to the same peak loudness. So if you stack a quiet layer and a loud layer, or draw a tiny ripple, the result still comes out at full level — and two different frames in a wavetable play back equally loud no matter how you shaped them. There's nothing in the shape controls that lets you say "this one should be half as loud."

That's what the Gain knob (just under the waveform's name/colour row, on the right) is for. Turn it down toward 0 to make this waveform quieter, up toward 2 to make it louder; 1.00 is unchanged, and double-clicking snaps it back to 1.00. It changes the waveform itself — you'll see the preview shrink or grow — so when you sweep the Position knob to morph between a loud frame and a quiet one, you actually hear the volume swell and fade. Gain belongs to the waveform, so every place you've dropped that waveform shares it.

Multi-frame wavetables

One layered cycle gives you a single timbre. Click + Add Frame to stack several distinct cycles into a wavetable. The synth gets a Position knob that crossfades between frames as you sweep it — automate Position over the course of a note and the timbre morphs in real time. Modulate it from an LFO for cyclic timbre wobble, or from velocity for "play harder = brighter."

Each frame has its own layer stack, edited independently. The frame tabs along the top let you switch between them; adding a new frame duplicates whichever frame was active so you have a starting point instead of a blank canvas.

N-dimensional grids

A grid starts out as a single row of cells, drawn as a segmented line: each cell is a tick-marked segment along the line, with its waveform shown as a dot in the middle and an index label like [0], [1] below. That's the 1D morph — one Position knob sweeps along the row. Click + Dim to add a second axis, and the line becomes a 2D checkerboard of cells with a second Position knob; add more dimensions for a cube and beyond. Each axis is independent, so you can wire them up to different modulation sources for orthogonal control over different aspects of the sound.

Most users won't go past 2D, but the option is there for ambitious sound design where you want, say, brightness on one axis and detune-spread on another.

A Position knob only shows up once its axis has something to morph through. A grid axis that's still one waveform wide has no second frame to crossfade to, so it stays knob-free — grow it to two or more waveforms and its Position knob (and its Mod: Position cable input) appear automatically. Shrink it back to a single waveform and the knob goes away again.

Empty cells and volume

A grid doesn't have to be completely filled — you can leave some cells empty (no waveform). By default SEANCE keeps the sound at full volume as you morph across the gaps: it spreads the morph over whichever cells are filled, so an empty cell never makes the sound quieter. This is the Empty cells fade volume toggle (below the axis-size sliders), and off is the default. If your grid has no empty cells, the toggle does nothing.

Turn Empty cells fade volume on when you actually want the gaps to be heard — morphing toward an empty cell then ducks the sound toward silence, so a sparse grid becomes a rhythm of swells and dropouts. It's the same idea as Scatter mode's Distance fades volume toggle, just for grid cells instead of scattered dots.

Scatter mode

The default Grid mode lays your frames out on a regular N-dimensional grid. That's the obvious way, and it's what you want when your morph axes have a clear evenly-spaced meaning. But sometimes you have a few frames that don't fit a grid neatly — three frames at the corners of a triangle, or a cluster of frames in 3D space that morph into one another based on proximity rather than position-on-an-axis.

Click Mode: Grid in the toolbar to switch to Mode: Scatter. Now each frame has a free position vector (X, Y, optionally Z, and beyond), and you can drag the frames around in the viewport. The synth interpolates between frames based on the current Position values using a Wendland radial basis function — frames near the current position blend in, frames far away contribute less. The result is a smoother and more organic morph than grid interpolation, especially when frames don't sit at grid intersections.

You can always get back. The conversion button reads ↩ Back to Grid when an exact, lossless return is possible (you converted from a grid and haven't moved any dot off its original cell). If you've since edited axes or dragged dots around — or you built the wavetable in Scatter from the start — the button instead reads Convert → Grid and lays your dots out into a simple one-row grid (one cell per dot) so you're never stuck in Scatter mode.

Scatter starts out as a line: a single horizontal axis with your dots strung along it, draggable left and right. Use + Dim to grow it into a square (two axes), then a cube, and so on — the same + Dim / − Dim buttons that add morph axes anywhere. Take the line's one axis away with − Dim and the viewport becomes a small dashed circle — a compact drop target with no line or square, just a "drag a waveform here" affordance to remind you that you can drop sounds in to begin. (How many of these axes you can actually sweep is a separate question — see below.)

Use the per-frame coordinate sliders below the viewport to numerically place a frame if dragging doesn't get you the precision you want. There's one slider per axis the view has (one for the line, two for the square, and so on) — so you can place a frame along every visible axis, even a lone dot that doesn't span anything yet. That's how you set frames up to spread apart: place them at different coordinates and the morph axes appear (see below). Note this is a placement control and is separate from how many Position knobs the synth shows.

Just like a grid axis only becomes a Position knob once it has two or more cells to morph between, a scatter axis only becomes a Position knob once your dots actually spread out along it. The rule is per-axis: with one dot (or none) there's nothing to traverse, so no Position knobs appear at all. Spread two dots apart horizontally and an X knob appears; spread them vertically instead and you get a Y knob instead — each axis shows up on its own, only when the dots differ along it. Drag a dot back into line with the others and that axis's knob disappears again. So if you place a sound and no Position knob shows up, that's expected — give it a neighbour and pull them apart to create an axis to sweep.

Distance fades volume

By default the scatter blend is normalized: wherever you put the Position, the in-range frames are mixed into a full-volume average. Moving around changes which frames you hear, but never the overall loudness — and a lone frame always plays at full volume no matter where Position sits.

Flip on the Distance fades volume toggle (below the RBF radius slider) and the blend uses each frame's raw proximity weight as its gain instead. Now every scatter dot is a little "loudness island": loudest right at the dot, fading down to silence at the edge of its radius, and silent in the empty gaps between dots. As you sweep Position across the field you walk past each dot in turn, swelling it in as you approach and ducking it out as you leave — the scatter equivalent of moving a listener through a room of sound sources.

This toggle only changes the gain math; it doesn't add or remove any Position knob. Position knobs come purely from how your dots are spread out (see below), so you need at least two dots spanning an axis before there's anything to automate either way.

The 3D anaglyph viewport

For 3D scatter spaces (or higher, with the projection combo controlling which axes are shown), there's an optional anaglyph 3D rendering mode. Toggle 3D in the toolbar, put on red/cyan glasses, and the frame positions appear in stereoscopic depth. This is mostly useful as a visualization aid when you're trying to keep track of where many scatter frames sit relative to each other in a 3D-or-higher space.

The IPD, viewing distance, and depth sliders let you tune the stereo for your eyes and screen — average IPD is around 63 mm, typical viewing distance ~60 cm. Adjust depth for more or less dramatic 3D protrusion.

Morphing & shape-bending (warp)

SEANCE has two kinds of "morph", and it keeps them separate on purpose:

  • Wave-defining morphs generate the wave itself — PWM, Hard Sync, FM, Phase Distortion. You pick one from the layer's wave-source button, under Presets → With parameters (they're grouped there because, unlike a plain Sine or Saw, each carries its own defining knob). A layer has exactly one wave source, and choosing a generator reveals its own knob (PWM's Duty, FM's Index/Ratio, …), each with a Pin checkbox to modulate it live.
  • Arbitrary-wave morphs reshape whatever wave you already have — fold it back on itself, clip it, saturate it for warmth, bend its read position, bitcrush it, and more. These are the warp stages you build with + Add.

A warp chain shows up as the Summation Morph strip below the preview, which reshapes the combined sound of all the layers. (A layer reshapes its own cycle only through its wave source — a Type-1 generator like Pulse / FM / Phase Distortion; there's no separate per-layer warp chain.) The Summation Morph belongs to the frame you're editing — each frame keeps its own chain, so in a multi-frame table you can give one frame a soft clip and another a fold, and they shape themselves independently before the Position knob blends between them. Press + Add to put a stage on the chain. Each stage has:

  • A checkbox to switch it on or off without deleting it.
  • A method button — click it to pick the effect. The menu is grouped by kind, and the higher-quality picks have a ★ star.
  • An amount slider from 0 (no effect) to 1 (full).
  • A Pin checkbox — see below.
  • ▲ / ▼ arrows to move the stage earlier or later in the chain.
  • An X to remove it.

The order of the stages is part of the sound. Folding and then clipping a wave gives a different result than clipping and then folding, so the chain runs top-to-bottom and the ▲ / ▼ arrows let you rearrange it until it sounds right. You can stack as many stages as you like — two or three is plenty for most sounds.

The real magic is that each stage's amount is something you can modulate. Tick the stage's Pin checkbox (it used to be called "Mod") to give that amount a control input on the synth node, then wire an LFO, oscillator, or envelope into it — now the waveform's shape moves as a note plays, the way a sweeping filter does but on the waveform itself. Leave Pin unchecked and the stage costs nothing extra (it's baked into the wave). (If you reorder a stage you've wired up, the modulation follows that stage to its new spot, so you don't have to re-wire anything.) The same Pin checkbox also sits next to each layer's Phase and Amplitude sliders — and, for a generator layer, next to its extra knob (PWM Duty, FM Index/Ratio, …): tick one and a cable can sweep that value live. This works on single- and multi-frame tables alike — the synth re-bakes just the frame being modulated.

Not sure where to start? The Summation Morph's library row has a status label (showing whether the chain is independent or linked to a saved morph) and three buttons: Unlink, Use Library…, and Save to Library. Use Library… opens a picker listing built-in starter chains — Warm Saturation, West Coast Fold, Lo-Fi Crush, and more — that drop a ready-made stack into the editor you can then tweak, plus any morphs you've saved yourself. Every entry in the picker loads a chain, so you always get something. Saved morphs offer a Sync to library checkbox: on, the chain stays live-linked (edits flow both ways); off, you get a one-time independent copy. (Built-in starter chains always copy.) Unlink breaks an existing live link while keeping the current chain as your own independent copy (greyed out unless the morph is currently linked). These live in your project's Asset Library too (under Morph Algorithms, marked with a ★), right alongside any chains you Save to Library yourself to reuse across frames.

One note: captured (granular) waveforms and inharmonic stacks only offer the value-shaping warps (clip, fold, saturate, …), not the read-position ones — those play as a live, continuous stream, so there's no fixed cycle position to bend.

Shaping how each note fades in and out (the envelope)

A wavetable defines what a single cycle sounds like; the amplitude envelope defines how each note swells in and dies away when you play it. Click the Envelope… button in the wavetable editor's top toolbar (it opens in its own window) to set the Attack, Hold, Decay, Sustain and Release of the synth — short Attack for a plucky stab, long Attack and Release for a slow pad.

Each of the three ramps (Attack, Decay, Release) has a curve knob right under the sliders: leave it centred for a straight line, turn it right for a slow start that speeds up (the classic "exponential" feel), or left for a fast start that eases out. Double-click a curve knob to snap it back to straight. It's one knob that bends the whole shape — you almost never need the deeper …Curve… editors beside it. The little preview at the top of the envelope window updates as you turn the knobs, so you can see the shape you're making. (The same Envelope… button lives in the Frequency-Domain editor, and every tonal synth node also has it on its right-click menu.)

One fixed timbre? Use a single-cycle oscillator instead

Everything above is about building a wavetable — several cycles the synth morphs between. But sometimes you just want one waveform, authored your favourite way, played as a plain oscillator with no morphing. For that, each of these ways to build a single cycle is also available as its own instrument node: Layered, Spectral (frequency-domain), Wavelet Space, Inharmonic, and Granular. Add one from the node menu just like any other instrument.

These open a focused editor — the same authoring surface as the matching wavetable frame type, minus the wavetable-only parts (no Library/Cells panels, no Position morph, no "number of waveforms"). You still get a Gain control, a Preview button, the Envelope… button (the same Attack/Hold/Decay/Sustain/Release shape described above), and the Morph (shape-bending) panel. Reach for these when you want one solid timbre; reach for the full Waveform synth when you want that timbre to move.

Want to turn a recording into one repeating cycle? Add a Granular node, capture some audio into it (capture from song, mic, or file), and set its Freeze mode to Single cycle. It detects one pitch period in the recording and loops just that cycle — a clean single-cycle oscillator built from your own sound. (This replaced an old "Sample" oscillator that never had working capture.)

Bending a sound on the wire — the Waveshaper effects

The same shape-bending curves you can apply inside a wavetable frame (Soft Clip, Wavefold, Tube Saturate, Bitcrush, and so on) are also available as standalone Waveshaper (amplitude morph) effect nodes — one per curve, found in the node menu. Drop one anywhere in your signal chain and turn its single knob to dial in the amount. It's the same math as the in-frame morph, so a sound you shape inside a wavetable and one you shape on the wire come out identical — handy when you want to add grit or fold to a whole mix rather than to one instrument's waveform.

Workflow tips

  • Start with one layer, build up. Hit Add Layer only when the current sound is missing something specific. Stacking too many layers makes it hard to hear what each one contributes.
  • Use harmonic ratios to sculpt timbre. Pure integer harmonics (1, 2, 3, 4…) give pitched, organ-like sounds. Non-integer ratios (1.5, 2.7, …) sound bell-like or metallic. Lots of layers at integer harmonics with carefully chosen amplitudes can imitate real instruments via additive synthesis.
  • Frames don't have to be wildly different. Subtle frame-to-frame variation gives you a smooth, alive timbre that doesn't sound like crossfading between two different instruments. Big jumps between frames give you dramatic morphs better suited for sweeping pads.
  • Wire Position to a Signal Shape (LFO/envelope). A slow LFO on Position turns any wavetable into an evolving pad. An envelope on Position gives you per-note timbre evolution — bright at the start, mellower at the end.

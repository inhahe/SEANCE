Convolution Filter

Home

A convolution filter applies a custom impulse response (IR) to audio passing through. The editor lets you draw the IR as a curve, generate it from a preset (lowpass / highpass / bandpass / echo), or load an IR from a .wav file.

Two drawing modes:

  • Points — draw a smooth curve via Catmull-Rom control points. Default, good for filter shapes.
  • Freehand — draw individual sample values directly with the mouse. Good for surgical per-sample edits.

Ctrl+mouse wheel zooms in on the IR up to 128×, plain mouse wheel scrolls. When zoomed in enough that each sample is ≥5 pixels wide, a sample-boundary grid appears and individual samples are shown as stems with dots.

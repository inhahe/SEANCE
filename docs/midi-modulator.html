MIDI Modulator

Home

The MIDI Modulator takes one MIDI input and N configurable Signal inputs. Each signal modulates a MIDI attribute on the passing stream — velocity (sample-accurate, applied to each note-on), pitch bend, mod wheel, channel aftertouch, or an arbitrary CC number. Add more signal inputs via the editor's + Input button; each rule picks a target and an amount.

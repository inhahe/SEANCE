Recording Automation

Home Graph Basics Piano Roll

Automation is a knob that moves itself over time. Instead of drawing those moves by hand in a piano-roll lane, you can perform them: press Play, grab a knob and wiggle it, and SEANCE writes your moves into that parameter so they play back the same way next time. This is the classic "write automation" workflow, and it's what the transport's Auto button does.

Automation vs. Freeze. These sound similar but do different jobs. Automation recording captures the knob moves you make — the authored parameter motion. Freeze (right-click a node → Freeze) records the node's actual sound to audio, so a patch with a free-running LFO or internal randomness plays back bit-for-bit identically. Reach for automation when you want to shape a parameter over time; reach for Freeze when you want to lock a sound exactly as you last heard it.

The Auto button — three modes

The Auto button on the transport bar cycles through the global record mode each time you click it. It turns red when armed:

  • Off — nothing records, ever. This is a safety gate: while Auto is Off, no knob can overwrite its automation, so you can play a project back without any risk of clobbering your work. (Start here.)
  • Touch — a knob records only while you're holding it. Grab it, drag, let go — just the part you touched is rewritten; everywhere you didn't touch keeps its old automation. This is the everyday "punch in a fix here and there" mode.
  • Latch — a knob starts recording the moment you first grab it and keeps recording (holding the last value) until you press Stop, even after you let go. Use it to overwrite everything from a point onward.

Record a move

  1. Click Auto until it reads Touch (it turns red).
  2. Press Play (or Space).
  3. Grab a parameter — the value rows on the bottom of any node — and drag it while the song plays. The row lights up with a red outline to show it's recording.
  4. Let go, and press Stop. Your move is now saved into that parameter's automation lane. Rewind and press Play again to hear it play back on its own.

Made a mistake? Ctrl+Z undoes the whole recording pass in one step. Want to redo a section? Just record over it again — the new pass replaces the old points wherever you touch.

Per-node and per-param control

The Auto button sets the global mode, but you can override it for a single node or a single parameter — handy when you want to arm just one knob and leave everything else alone.

  • Right-click a parameter row → Automation — set that one knob to Inherit (follow the global Auto button), Off, Touch, Latch, or Write. The submenu header shows the mode that will actually take effect after combining global + node + param.
  • Right-click a node → Automation — the same choices, applied as the default for every knob on that node.

The order of priority is parameter → node → global: a parameter override beats a node override, which beats the Auto button. And because the global Off is a hard gate, nothing records while Auto is Off, no matter what a node or param override says — so loading a project can never quietly overwrite your automation.

What's "Write"? Write records the entire pass at the knob's current value whether or not you touch it — it flattens that parameter to one steady value across the whole song. It's the "just make this stay put" tool. Because a global Write could wipe every lane in the project at once, Write is only offered as a per-node or per-param override, never on the Auto button.

Muting automation without deleting it

Sometimes you want to hear a knob without its recorded automation for a moment — to compare, or to tweak it by hand. You can mute lanes non-destructively; the points stay saved and resume the instant you un-mute:

  • Right-click a node → Automation → Ignore automation on this node — mutes every lane on that node.
  • Right-click a param row → Automation → Bypass this lane — mutes just that one parameter.

Reading the graph

SEANCE shows you the recording state right on the node so you're never guessing:

  • A hollow red dot after a param name = it's armed (grabbing it during playback will record).
  • A solid red outline around a param row = it's recording right now.
  • A grey dot = that param has automation but the lane is muted.
  • An A: badge (or a slashed A) in a node's title bar = that node has an automation override (or has its automation ignored).
Hosted plugins: dragging a knob inside a plugin's own editor window during playback records too — arm Touch or Latch, press Play, and wiggle the plugin's knob. Because a plugin's knobs don't live on the node body, the whole node lights up with a red outline while it's recording (instead of a single row). One quirk: a few plugins don't tell SEANCE exactly when you grab and release a knob, so Touch falls back to stopping a moment after you stop moving. If a capture ever feels cut short, use Latch instead. Moves from a hardware MIDI controller mapped via MIDI Learn are recorded too: twist the physical knob during playback and it captures into automation just like dragging the plugin's own knob.

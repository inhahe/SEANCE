Trigger Node

Home Graph Basics MIDI Modulator

A Trigger node sits on a MIDI cable and fires extra events whenever a note passes through. The original note still flows through unchanged — the trigger just adds stuff. Use it for harmonies, octave doubles, chord generation, drum flams, key-range gates that fire only on certain pitches, probabilistic ghost notes, or for kicking off control signals (envelopes, LFO retriggers, ramps) in time with what you play.

Add one from Effects → Trigger in the right-click menu. Wire your MIDI input into its MIDI In, wire the MIDI Out to your synth, and wire the Signal Out to whatever parameter you want envelope-shaped. The node also has an Audio In pin used by the Audio Threshold firing mode (see below) — leave it unwired if you're not using that mode. Double-click the node to open the rule editor.

Trigger vs. Script: both nodes can put new MIDI notes into the graph, so it's worth knowing which to reach for. The Trigger is reactive and rule-based — it watches the notes you play and decorates each one (harmonies, octaves, chords, flams, ghost notes), all by filling in form fields, no programming. The Script is continuous and programmatic — it runs on the clock (free-running LFOs, transport-locked sweeps) and writes generative sequences/arpeggios as a little program. Rule of thumb: "when I play a note, also do X" → Trigger; "emit this signal or pattern over time" → Script. Two things only the Trigger can do: fire from an audio threshold (side-chain a kick into note generation — the Script can't read the audio buffer), and build chords/flams/probabilistic notes with zero scripting.

Rules

The editor shows a list of rules. Each rule has three sections that together describe one thing the trigger does:

  1. A match — which incoming events activate this rule.
  2. A firing condition — what kind of event triggers it (a note-on, a note-off, or audio crossing a threshold).
  3. A target action — what the rule emits when it fires (a MIDI note or a signal shape).

Rules evaluate independently every time a matching event arrives, so you can stack many at once — e.g. one for a third above, one for a fifth above, one for an octave below, and one signal envelope all triggered by the same note-on. Click + Add MIDI Rule or + Add Signal Rule at the top to add a new row. Each row has its own controls and an X button to delete it.

Match (which notes the rule listens to)

By default a rule fires for any incoming note. The match section lets you scope it more tightly:

  • Pitch range (Min / Max) — only fire when the incoming note's pitch is in this range. Default 0..127 (everything). Set Min=60 Max=72 and the rule only fires for notes in the middle octave. Useful for split keyboards (one rule for the bass register, a different rule for the lead register) or for gating drum-style rules so only specific pads trigger them.
  • Velocity range (Min / Max) — only fire when the incoming velocity falls inside this band. Default 1..127. Set Min=1 Max=40 to fire only on quiet notes (good for "ghost notes"), or Min=100 Max=127 to fire only on hard hits (good for "accent" decorations). Applies to Note On rules only — Note Off carries no meaningful velocity, so the velocity match is ignored when the firing condition is Note Off.
  • Probability (0..1) — stochastic gate. The rule rolls a die against this value every time and skips firing if it loses. 1.0 = always fires; 0.5 = fires half the time; 0.0 = never fires. Combine with the pitch and velocity ranges for things like "every snare hit has a 30% chance of an extra ghost note 1/16 later".

Firing condition

Each rule fires in response to one of three event types:

  • Note On (default) — fires when a matching note-on arrives. This is what you want for harmonies, chord generation, per-note envelopes, etc.
  • Note Off — fires when a matching note-off arrives. Useful for "release decorations" — a soft echo when a key is released, or a signal envelope that ramps down when you let go of a note.
  • Audio Threshold — fires when audio on the Trigger node's Audio In pin crosses a threshold in dBFS, with a minimum re-trigger gap to avoid double-firing on noisy transients. The classic use is "make a synth fire a note every time the kick drum hits", side-chain-style: wire your kick bus (or any audio you want to follow) into Audio In, set the threshold to taste, and the rule fires on each transient. Audio In is only needed for this firing mode — leave it unwired if all your rules use Note On / Note Off.

MIDI rule action

A MIDI rule emits one new MIDI note when it fires. Its fields:

  • Pitch offset — semitones relative to the incoming note. +12 = octave up, −12 = octave down, +7 = a fifth up, 0 = same pitch as the original (useful for delayed echoes / flams).
  • Velocity delta — added to the incoming velocity. −30 makes the new note 30 steps quieter than the original (great for ghost notes and flam tails); +20 makes it louder. Not a multiplier — it's straight addition into the 0..127 range.
  • Delay — time before the new note fires, measured in beats (so it stays musical when the tempo changes). 0 = simultaneous with the original; 1/32 = a 32nd-note later; 0.25 = a quarter-note later.
  • Length — duration of the new note, also in beats. Default is a quarter-note (0.25).
  • Channel — MIDI channel (1..16) the new note is emitted on. Default 1. Useful when you're feeding a multi-timbral synth or a router that splits channels to different instruments — you can send the original on channel 1 and the harmony on channel 2.

Signal rule action

A signal rule generates a control signal on the Signal output. Wire Signal Out to a synth parameter (filter cutoff, amp envelope, pitch, etc.) and the signal modulates it every time a matching note hits.

Five shapes are available:

  • Step — jumps instantly from the Rest value to the Peak value, holds for Hold milliseconds, then drops back. Good for "open/close the gate for a moment" behavior.
  • Envelope — classic ADSR. Attack ms to peak, Decay ms to the sustain level (a fraction of peak), held while the source note is held, then Release ms back to rest. This is the general-purpose modulation envelope.
  • Ramp — linear slew from the current output to the Peak value over Ramp duration milliseconds, then returns. Good for slow fade-ins on filter cutoff or pitch glides.
  • From velocity — outputs a constant value computed from the triggering note's velocity: scale × (velocity / 127) + offset. Held for the rule's Hold duration. Use for "play harder = modulate further" mappings.
  • Curve — user-defined breakpoint curve. Lets you draw an arbitrary shape with time-value points (linear interpolation between them). Plays from the first point to the last when the rule fires, then holds the last value. Use when none of the four parametric shapes get you the contour you want.

Common to all shapes: Peak value and Rest value set the high and low ends of the output range. Flip them (Peak below Rest) to invert the polarity without rewiring.

Shape overlap

If a new shape fires before the previous one has finished, the newest shape replaces the old one on the Signal output. Each shape captures its parameter values at trigger time, so editing the rule's parameters after a shape has started doesn't retroactively change a running shape.

Presets

Five preset buttons load common configurations as starting points. Each preset replaces the current rule list, so use them to get familiar with what rules look like, then tweak.

  • + Octave — one MIDI rule that doubles every note one octave higher. Instant fat sound.
  • Chord — two MIDI rules at +4 and +7 semitones. Combined with the original note passing through, you get a major triad (root, major third, perfect fifth) per incoming note. Change the +4 to +3 for a minor triad.
  • Flam — two soft ghost copies of the note at 1/32 and 2/32 of a beat after the hit, each 30 then 60 velocity steps quieter. Drum-machine "flam" effect on snares; works for any percussive sound.
  • Pluck — one Signal envelope rule (2 ms attack, 200 ms decay, no sustain, no release) that fires a short pluck-shaped envelope on every note. Wire its Signal Out to a synth's filter cutoff or amp envelope to add per-note transients independent of the synth's own envelope.
  • Velocity follower — one Signal rule whose output value is proportional to the note's velocity (held for ~1 s). Use to drive parameters from how hard you play, beyond what built-in velocity sensitivity already does.

How rules combine

When an event comes in, the trigger walks the rule list and fires each rule independently. MIDI rules each emit one new note (offset, delayed, scaled, on the chosen channel). Signal rules each schedule one shape on the Signal output. The original incoming event also passes through to MIDI Out.

If you add many rules, the trigger can multiply note traffic significantly — a chord rule sends 2+ extra notes per incoming note, and chaining multiple triggers compounds further. Watch your synth's voice count if you do this aggressively.

Tip: the Trigger is a generator, not a filter. To suppress or mute incoming notes (e.g. a key range gate that drops out-of-range notes, an octaver that replaces the original instead of doubling it), use a different effect node — the Trigger always passes the original through.
